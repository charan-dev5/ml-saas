# ML Predict 

A Machine learning SaaS application that allows users to upload CSV data and receive instant predictions.

## Features
- User registration and login
- Protected dashboard
- CSV file upload
- ML predictions using Random Forest
- Deployed live on Render

## Technologies
Flask, SQLAlchemy, scikit-learn, flask-login, gunicorn, Render
